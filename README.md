# Playroom

Playroom 是一個以瀏覽器開啟的即時多人遊戲空間，提供賽跑、抽鬼牌、投票與全站聊天室。介面採深色像素掌機風格，控制項與資訊區塊保持緊湊，並為深色背景提供高對比文字。

## 功能

- **衝刺賽跑**：倒數後開始，點擊會由瀏覽器批次送出；即時顯示賽道、名次與結果。
- **抽鬼牌**：由後端洗牌、發牌與自動配對，最後持有鬼牌者落敗；等待時可標記手牌誘導抽牌者。
- **多人投票**：一般投票或 Scrum Story Point 估點。全員投票後自動開牌，局主也可強制公開、開啟下一題及清除題目歷程。
- **答項範本**：可儲存、套用與刪除投票答項組；分享範本會產生分享碼。
- **即時聊天室**：平台、遊戲與房間各有聊天頻道，支援在線成員、暱名修改與收合面板。
- **房間與結果**：以短代碼分享房間，可選擇密碼保護；完成後保留結果、遊戲事件與聊天摘要。
- **站台管理**：設定管理者密碼後可搜尋、選取及批次刪除房間。

## 啟動

```bash
npm install
npm run dev
```

開啟 <http://localhost:3000>。正式模式：

```bash
npm run build
npm start
```

## 設定

複製 `.env.example` 為 `.env` 後即可設定本機環境；啟動時會自動讀取。已由執行環境提供的環境變數會保留，不會被 `.env` 覆寫。

```bash
cp .env.example .env
```

| 環境變數 | 預設值 | 說明 |
| --- | --- | --- |
| `PORT` | `3838` | HTTP 與 WebSocket 服務埠。 |
| `HOST` | `0.0.0.0` | 監聽位址。 |
| `BASE_PATH` | 空白 | 公開 URL 前綴，例如 `/playroom`；需搭配反向代理移除該前綴。 |
| `DATABASE_FILE` | `playroom.sqlite` | SQLite 資料庫檔案位置。 |
| `ADMIN_PASSWORD` | 未設定 | 啟用 `/admin` 管理登入的密碼。 |

資料庫會保存房間設定、事件、結果、聊天室訊息與範本。玩家端會在瀏覽器保存近期房間、重連資訊與自己儲存的範本 ID。

## 驗證

```bash
npm test
```

此命令會先進行 TypeScript 建置，再執行賽跑、投票與抽鬼牌的行為測試。
